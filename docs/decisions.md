# Decisions and limitations of choices

- **Data acquisition:** A's exact repository is404; B's data routes are403. Neither publisher's claimed count is an acquired dataset. The JACS Au predecessor table is downloadable but opaque PDF names cannot be proven unique study IDs, so it is excluded. NLP expanded entity tables also fail experiment/provenance checks. Chosen alternative: independently downloaded Wang copper-modifier FE workbook, pinned Git commit and SHA, Apache2.0 repository metadata. No source pooling.
- **Task revision:** Broad CO2RR labels are unavailable with verified provenance. Use an explicit highest-reported individual-carbon FE label from real numeric FE columns; this narrows the scientific claim to recorded product ranking in organically modified copper, not complete selectivity or unseen catalyst-family prediction. An alternative would stop after an audit; explicit DOI+FE+conditions permits a narrower real benchmark. This is disclosed before models.
- **Provenance vs size:** Do not guess DOIs for104 raw rows in citation blocks lacking an explicit DOI. Restrict source carry to workbook's explicit numbered bibliography blocks. Small primary n is a consequence, not a target.
- **Catalyst representation:** Avoid full SMILES identity or near-unique text. Simple recorded atom tokens+polymer category provide limited composition features without adding DFT/large-model descriptors. Polymer repeat strings are representation-dependent and not molecular formulas; this limitation remains.
- **Class coverage:** >=10records and >=3DOIs is prospectively chosen for a minimally interpretable3-fold study benchmark. It excludes one-study acetic acid and8-record formic acid. Changing this after scores would be an amendment, not a default improvement.
- **Models:** Fixed small CPU models, zero tuning; group-safe sigmoid only where source/class coverage permits. Partial calibrated study predictions are secondary and matched to raw predictions on the identical56-row subset, not compared against86-row raw scores.
- **Risk curves:** Descriptive exploration only; no test-selected deployment threshold or claim of experimental recommendation.
- **Uncertainty:** Cluster intervals condition on saved fits;22DOIs are few and selection-biased, with correlated OOF training folds. They do not include refitting, curation uncertainty or literature bias.
